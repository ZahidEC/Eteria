# Invitación Roblox interactiva 2.0

## Qué trae esta versión
- Hero mucho más temático con chat bubbles y UI de juego
- Inventario rápido tipo hotbar
- Cuenta regresiva
- Pase VIP / Game Pass
- Daily reward (100 coins)
- Badges
- Leaderboard
- Selección de avatar
- Selector de juegos favoritos Roblox
- Minijuego obby de 5 niveles
- Recompensa final desbloqueable
- Galería modal
- Confirmación por WhatsApp con juego favorito y coins
- Menú móvil y diseño responsive

## Archivos
- `index.html` — estructura principal
- `css/styles.css` — estilos y responsive
- `js/config.js` — datos fáciles de editar
- `js/app.js` — interacciones
- `img/` — ilustraciones y tarjetas SVG originales

## Personaliza rápido
En `js/config.js` cambia:
- `celebrantName`
- `age`
- `eventDate`
- `eventTime`
- `eventPlace`
- `passTitle`
- `whatsappNumber`
- `mapsUrl`
- `eventISO`
- `eventEndISO`
